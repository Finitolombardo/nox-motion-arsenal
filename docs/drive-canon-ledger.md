## Interpretation rules

- `fusion-core`: source explicitly identifies a consolidation/core/fusion decision.
- `legacy-alias-wrapper`: source preserves an old identity as a route/alias/wrapper; it is not a hard deletion.
- `keep-standalone`: source explicitly preserves a separate renderer/mechanism or source-gated standalone.
- `active-core`: source explicitly calls a target active/canonical; only static-ID matches appear in the ID table.
- Later lines in the declared source order are the `latest_source_evidence`; the JSON retains source order and counts for auditability.
